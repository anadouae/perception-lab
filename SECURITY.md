# Security & ethics — Perception Lab

- Frames / detections in the demo are **SIMULATED** (`provenance: SIMULATED`).
- This is **traffic congestion / occupancy analytics**, not surveillance, face recognition, or access control.
- Do not point this tooling at real people without legal basis, DPIA, and authorized feeds.
- Kafka credentials via environment only; never commit broker passwords.
- Container runs as packaged CLI; keep brokers on private networks.
